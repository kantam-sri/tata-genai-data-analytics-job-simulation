# Geldium Delinquency Prediction — GenAI Powered Data Analytics Project

Completed as part of the Tata GenAI Powered Data Analytics Job Simulation (Forage).

## 📌 Overview
This project analyzes a 500-record customer financial dataset to predict loan
delinquency risk and recommend a collections strategy, using GenAI-assisted
workflows at each stage.

## ✅ Tasks Completed

### 1. Exploratory Data Analysis & Risk Profiling
- Reviewed 19 variables across 500 records
- Handled missing data (Income, Loan_Balance via median imputation; 
  Credit_Score via mean imputation)
- Identified key early risk indicators

### 2. Predictive Model Plan
- Chosen model: Logistic Regression (interpretable, regulator-friendly)
- Alternative: Random Forest / Gradient Boosting
- Top predictors: Income, Credit Utilization, Missed Payments, 
  Debt-to-Income Ratio, Credit Score
- Evaluation: Accuracy, Precision, Recall, F1, AUC-ROC, Confusion Matrix
- Fairness checks: demographic parity, disparate impact, SHAP explainability

### 3. Fairness / Equality Analysis
- Cross-group performance comparison table (Task 5)

### 4. Business Summary Report
- Translated model insights into a SMART recommendation framework 
  for the Collections team

### 5. AI-Powered Collections Strategy Presentation
- Stakeholder-ready deck summarizing findings and proposed strategy

## 🛠 Tools & Skills
Excel, Word, PowerPoint, GenAI prompting, Logistic Regression, 
EDA, fairness/bias evaluation
